# Shadow of Israphel website

Public website for an independent Minecraft fan adventure.

Live site: https://shadowofisraphelproject.online/

Static HTML, CSS, and JavaScript, hosted on GitHub Pages from the main branch. No build step. To preview locally, open index.html or run `python3 -m http.server 8080`. Media is configured in media.js.
